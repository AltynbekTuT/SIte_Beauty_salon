# Khadisha Beauty Salon

Демонстрационный сайт салона на HTML, CSS, Bootstrap и JavaScript.

## Страницы

- `index.html` — главная страница салона
- `services.html` — каталог из 14 услуг, категории объединяются по строкам, цены показаны без имён специалистов
- `booking.html` — выбор услуги и одного из двух подходящих специалистов, расчёт цены и демонстрационная форма записи
- `masters.html` — 12 карточек мастеров шести направлений
- `reviews.html` — карточки отзывов и форма отзыва
- `contacts.html` — контакты и форма вопроса

## Каталог и тарифы

Общий список находится в `js/main.js`. Каждая услуга связана с мастером базового тарифа и топ-мастером, их ценами и длительностью. Прайс, список специалистов при записи и список услуг в форме отзывов строятся на основе этого каталога. Добавляя услугу, обновляйте также пары мастеров и их профили в `MASTERS`.

В каталоге категорию услуг показываем один раз на несколько строк. В столбце «Мастер» указан только базовый тариф, в «Топ-мастер» — только повышенный тариф. Фильтр категорий и поиск сохраняют правильное объединение строк.

## Корзина и аккаунт

Корзина доступна в меню на каждой странице. Она хранит выбранные услуги и количество в пределах текущей сессии браузера. Кнопка записи открывает форму для первой услуги в корзине.

Формы входа и регистрации демонстрационные: сайт проверяет заполненные поля на стороне браузера, не отправляет данные на сервер, не создаёт пользователя и не сохраняет пароль. Форма записи также показывает пример заявки, но не отправляет её в салон.

## Демонстрационные данные

Имена мастеров, специализации, стаж, услуги и цены являются учебными данными. Сверьте их с салоном перед публикацией. Фотографии мастеров можно добавить в `masters.html`.

Для работы сайта подключите интернет: Bootstrap загружается с CDN.

## Изображения

Иллюстрации для направлений и демо-отзывов загружаются с Unsplash, авторы и ссылки на исходные страницы указаны рядом с фотографиями. Иллюстрации не являются снимками конкретных клиентов или мастеров. Для их отображения нужен интернет. На главной странице и в контактах также используются фотографии салона из исходного архива.
## Assignment 6 jQuery

- jQuery 3.7.1 подключён с официального CDN перед `main.js` и страницными скриптами на страницах услуг, записи и отзывов. Выбрана полная сборка, так как задание использует эффекты jQuery.
- `js/services.js` перерисовывает каталог из `SERVICES`, фильтрует его, объединяет категории и обрабатывает динамические кнопки корзины делегированным событием.
- `js/booking.js` строит зависимые списки услуги и мастера, пересчитывает цену и проверяет каждое поле с сообщением рядом с ним.
- `js/reviews.js` строит карточки из массива, проверяет форму отзыва и показывает карточку после успешного добавления.
- `old-js-version.js` содержит версии этих трёх файлов до переписывания и не подключается к страницам.
- Все проверки и формы остаются демонстрационными: серверной отправки нет.
