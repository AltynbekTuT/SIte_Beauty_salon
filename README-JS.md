# Краткая памятка по JavaScript

- `js/main.js` — общий каталог, цены, корзина и демо-формы входа/регистрации.
- `js/services.js` — поиск, фильтр по категориям, объединённые ячейки категорий и добавление услуги в корзину.
- `js/booking.js` — услуги из общего каталога, выбор одного из двух подходящих мастеров, подсказки о цене и длительности, демонстрационная заявка.
- `js/masters.js` — поиск и фильтрация 12 карточек мастеров.
- `js/reviews.js` — список услуг для отзыва из общего каталога и демонстрационное добавление отзыва.
- `js/contacts.js` — клиентская проверка формы контактов.

Корзина хранится в `sessionStorage` и очищается после окончания сессии браузера. Вход, регистрация, запись, отправка отзыва и форма контактов не соединены с сервером. Не вводите в учебные формы реальные пароли или конфиденциальные данные.

Чтобы добавить услугу, внесите её в массив `SERVICES` в `js/main.js` и назначьте ровно двух мастеров с соответствующими уровнями в `masterIds`. Профили этих специалистов должны быть указаны в `MASTERS`.

Иллюстрации процедур загружаются с Unsplash; возле каждого фото есть ссылка на страницу автора. Для загрузки изображений требуется интернет. Фото на странице отзывов являются иллюстрациями услуг, а не изображениями авторов отзывов.
## Assignment 6

Три прежних функции перенесены на jQuery 3.7.1: динамический каталог услуг и фильтры (`js/services.js`), онлайн-запись с валидацией (`js/booking.js`), карточки и форма отзывов (`js/reviews.js`). В jQuery-версиях обработчики назначаются через `.on()`, список карточек и таблица создаются из массивов, а для фильтров, ошибок и подтверждения используются эффекты. Сравнение с предыдущим чистым JavaScript находится в `old-js-version.js`; этот файл не подключён.

Для защиты: `.text()` вставляет обычный текст, `.html()` разбирает HTML-разметку; `.attr()` читает/задаёт атрибут разметки, а `.prop()` — текущее свойство DOM, например состояние checkbox через `checked`. Корзина и аккаунт в `main.js`, фильтр мастеров в `masters.js` и проверка формы контактов в `contacts.js` остаются отдельными функциями на обычном JavaScript; внутри переписанных функций два подхода не смешиваются.
