О проекте

Сайт создан для Khadisha Beauty Salon в рамках учебного проекта.

На данном этапе сайт написан на HTML5 без CSS и JavaScript.

Начиная с третьего задания подключён Bootstrap 5.3.3 (CDN), поверх него работает наш файл стилей. JavaScript мы сами не пишем.
