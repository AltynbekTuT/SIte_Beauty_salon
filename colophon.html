Технологический стек проекта

Данный веб-сайт построен исключительно с использованием чистого HTML5 в рамках учебного задания. В проекте не применяются CSS и JavaScript.

Стандарты кода и валидация

Все HTML-файлы проходят обязательную проверку через W3C HTML Validator. Для сохранения изменений в Git-репозитории используется сочетание клавиш Ctrl + S и последующий коммит через терминал.

Пример базовой структуры HTML5:

<!DOCTYPE html>
    <html lang="ru">
      <head>
        <meta charset="UTF-8">
        <title>Заголовок страницы</title>
      </head>
    </pre>
    
                
Отлик валидатора в терминале отображается следующим образом:

                
Document checking completed. No errors or warnings to show.

Подробнее о правилах семантики можно прочитать на официальном ресурсе: MDN Web Docs.
